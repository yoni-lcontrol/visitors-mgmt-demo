# Glossary

- **Access Group**: door-oriented access group in Amadeus8.
- **Security Group / MAG**: security/multi-access group concept in Amadeus8.
- **Access Level**: optional internal app abstraction that may unify Access Groups and Security Groups for read scenarios.
- **Cardholder**: person record in Amadeus8.
- **CardholderIdNumber**: business identifier field exposed by Amadeus8 cardholder APIs.
- **Push API**: Amadeus8 real-time event delivery mechanism using SignalR.
- **UID**: Amadeus GUID identifier for an entity.
- **API Key**: Amadeus API-facing string identifier used by many endpoints and lookup flows.
